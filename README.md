# CFD-Based Thermal Performance Optimization of a Data Center Cooling System

## Project Overview

This project analyzes airflow and heat transfer in a six-rack data center using Computational Fluid Dynamics (CFD).

## Tools Used
- SimScale
- ParaView
- Python
- Pandas
- Matplotlib

## Simulation Parameters
- Room Dimensions: 6m × 4m × 3m
- Number of Racks: 6
- Heat Load: 2 kW per rack
- Supply Air Temperature: 18°C
- Supply Air Velocity: 2 m/s

## Methodology
1. Developed a simplified data center geometry.
2. Defined rack heat loads and CRAC supply conditions.
3. Compared open-layout and hot-aisle/cold-aisle configurations.
4. Analyzed temperature and airflow distributions.
5. Processed results using Python and ParaView.

## Future Scope
- Optimize cooling energy consumption.
- Investigate different rack heat loads.
- Evaluate Power Usage Effectiveness (PUE).
- Explore AI/ML-based cooling optimization.
