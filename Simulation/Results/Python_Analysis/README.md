# Python-Based Data Analysis

This folder contains Python scripts for analyzing and visualizing CFD simulation data.

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Tasks
- Import and process CFD simulation data.
- Calculate rack inlet temperature statistics.
- Compare open-layout and containment configurations.
- Analyze temperature uniformity.
- Generate comparative graphs.

## Planned Scripts
- data_analysis.py
- temperature_comparison.py
- airflow_visualization.py

## Objective
Use Python-based data analysis to evaluate thermal performance and identify opportunities for data center cooling optimization.
