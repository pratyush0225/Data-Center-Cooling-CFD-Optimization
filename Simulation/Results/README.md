# CFD Simulation Results

This folder contains the results and visualizations obtained from data center cooling simulations.

## Analysis

- Temperature distribution across the data center.
- Airflow velocity and circulation patterns.
- Rack inlet temperature comparison.
- Thermal hotspot identification.
- Cooling performance comparison.

## Visualizations

The following plots will be added:

1. Temperature contour plots.
2. Velocity contour plots.
3. Open-layout vs. containment comparison.
4. Rack inlet temperature graphs.

## Tools Used

- ParaView
- Python
- Pandas
- Matplotlib

## Key Objective

Evaluate the effectiveness of hot-aisle/cold-aisle containment in improving thermal uniformity and reducing rack inlet temperatures.
