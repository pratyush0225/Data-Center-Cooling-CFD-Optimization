# CFD Simulation

This folder contains CFD simulation configurations and results for the data center cooling project.

## Simulation Cases

### Case 1: Open Layout
- Conventional rack arrangement.
- Analysis of hot and cold air mixing.
- Evaluation of temperature distribution.

### Case 2: Hot-Aisle/Cold-Aisle Containment
- Separated hot and cold airflow paths.
- Improved airflow management.
- Evaluation of cooling performance.

## Simulation Parameters
- Number of racks: 6
- Heat load: 2 kW per rack
- Supply temperature: 18°C
- Inlet velocity: 2 m/s

## Software
- SimScale
- ParaView
